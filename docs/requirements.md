# CopyCapsule - 需求文档

## 项目概述

CopyCapsule 是一款运行在 macOS 上的轻量级剪贴板历史管理器。它以菜单栏小图标的形式在后台运行，自动记录用户复制（⌘+C）的所有文字和图片内容，提供搜索、置顶、删除和再次粘贴等功能。

## 目标用户

- macOS 日常用户
- 经常需要回溯复制历史的内容创作者
- 对隐私敏感、希望数据存在本地的用户

## 功能需求

### F1 - 自动记录剪贴板
- **描述**: 软件在后台运行时，自动监听并记录用户复制到系统剪贴板的所有内容
- **支持类型**: 纯文本（text/plain）、富文本（RTF）、图片（PNG/TIFF）
- **监听方式**: 自动，无需用户手动操作
- **去重**: 连续复制相同内容不会产生重复记录

### F2 - 保留天数设置
- **描述**: 用户可设置历史记录的保留时长
- **可选项**: 1天、3天、5天
- **默认值**: 3天
- **行为**: 超过保留天数的记录自动清理（非置顶项）

### F3 - 历史面板
- **描述**: 点击菜单栏图标或按快捷键弹出历史记录面板
- **排列方式**: 时间降序（最新在上）
- **分组**: 置顶区域 + 按日期分组（今天、昨天、更早）
- **面板尺寸**: 默认宽380pt，高520pt，用户可自由缩放
- **关闭方式**: 点击菜单栏图标或按 Esc 关闭（v2 改为 NSWindow 模式）

### F4 - 置顶功能
- **描述**: 重要记录可固定在列表顶部
- **行为**: 置顶项不受保留天数限制，不会被自动清理
- **排序**: 按置顶时间降序排列

### F5 - 删除功能
- **描述**: 可手动删除任意历史记录
- **交互**: 每条记录卡片上有删除按钮
- **确认**: 无确认弹窗（直接删除），提供撤销提示（可选）

### F6 - 搜索功能
- **描述**: 通过关键词搜索历史记录
- **搜索范围**: 文字内容（全文搜索）
- **搜索方式**: 实时过滤，输入即搜
- **空结果**: 显示"未找到"提示

### F7 - 再次粘贴
- **描述**: 点击任意历史记录，将其内容重新写入系统剪贴板
- **反馈**: 点击后有短暂视觉反馈（绿色闪烁）
- **行为**: 复制后自动关闭面板（方便用户直接 ⌘+V 粘贴）

### F8 - 全局快捷键
- **快捷键**: ⇧⌘V (Shift+Command+V)
- **行为**: 按下后弹出/关闭历史面板
- **要求**: 无需辅助功能权限

### F9 - 开机自动启动
- **描述**: 用户登录 macOS 时自动启动 CopyCapsule
- **设置**: 在设置面板中开关
- **实现**: 使用 SMAppService（系统设置中可见）

### F10 - UI 设计
- **主色调**: 淡蓝色 (#5AACFA)
- **风格**: 简洁、直观、原生 macOS 风格
- **卡片**: 圆角矩形，轻阴影
- **图标**: SF Symbols 系统图标

## 非功能需求

### NF1 - 性能
- 剪贴板监听间隔: 0.5秒
- 搜索响应: < 100ms（1000条记录以内）
- 启动时间: < 1秒

### NF2 - 存储
- 数据库位置: ~/Library/Application Support/com.copycapsule.app/
- 无容量上限（由保留天数控制）
- 图片以 PNG 格式存储

### NF3 - 隐私
- 所有数据存储在本地
- 无网络请求
- 不收集任何用户数据

### NF4 - 兼容性
- 最低系统: macOS 14 (Sonoma)
- 架构: Apple Silicon (arm64)，可选 Universal (x86_64)

## 第二轮迭代（v2）新增需求

### F11 - 收藏功能⭐（长期储存）
- **描述**: 用户可收藏重要记录，收藏条目永久保留
- **存储**: 收藏条目不受保留天数限制，不会被自动清理
- **排序**: 收藏区排在最上方 → 置顶区 → 普通历史
- **编组**: 收藏数量达到 6 条时，自动折叠为一个可展开/收起的组
- **未满 6 条**: 正常展开显示，不折叠
- **交互**: 每条记录卡片右侧新增收藏按钮（星形图标），与置顶、删除按钮同一排

### F12 - 设置页面铺满面板
- **描述**: 点击设置按钮后，整个面板内容切换为设置页（不再使用 Sheet 弹窗）
- **返回**: 设置页有返回按钮，点击切回历史列表
- **面板尺寸**: 使用当前面板/窗口的完整尺寸

### F13 - 面板可自由缩放
- **描述**: 面板窗口支持用户拖拽边缘自由调整大小
- **最小尺寸**: 设定最小宽度和最小高度，缩小到极限后不可再小
- **默认尺寸**: 380×520pt（与原面板一致）
- **窗口标题**: "CopyCapsule"
- **窗口行为**: 从 NSPopover 改为 NSWindow，点击外部不自动关闭

### F14 - 修复图片复制问题
- **描述**: 修复从 Finder 复制图片或截图时，经常获取不到图片内容、只记录文件名的问题
- **目标**: 所有来源（浏览器、Finder、截图等）的图片都能正确获取 PNG 数据

### F15 - 支持任意格式文件
- **描述**: 从 Finder 复制的文件（PDF、Word、文件夹等）也记录到历史
- **存储方式**: 只存文件路径引用（不存文件本身），不占数据库空间
- **显示**: 卡片中显示文件图标 + 文件名
- **粘贴行为**: 点击后将文件路径写回剪贴板，用户可在 Finder 中粘贴
