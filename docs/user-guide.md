# CopyCapsule 使用指南

## 基本操作

### 打开/关闭窗口
- **全局快捷键**（默认 ⇧⌘V）：呼出/关闭剪贴板历史窗口
- **点击菜单栏图标**：左键打开/关闭窗口，右键 → `⌘Q` 退出
- **Esc**：关闭窗口并清除多选

### 复制内容
- **点击卡片**：将该项目重新复制到剪贴板（1秒绿色闪烁反馈）
- **Shift + 点击卡片**：多选模式（可批量打标签）
- 支持类型：文字、富文本(RTF)、图片、文件

### 搜索
- 在底部搜索栏输入关键词，实时筛选匹配的文字内容

## 标签操作

### 打标签
- **选中卡片 → ⌘G**：打开标签输入框
- 输入标签名 → 回车确认（自动补全已有标签）
- 最多 3 个标签/条记录
- 打标签后自动收藏该记录

### 标签筛选
- **点击底部标签胶囊**：切换选中/取消，支持多选（OR 逻辑合并显示）
- 选中标签显示绿色，未选中灰色

### 标签管理
- **双击标签胶囊**：重命名标签（所有关联记录同步更新）
- **Shift + 双击标签胶囊**：删除该标签组及所有关联记录（需确认）

### 标签导出
- **选中标签 → ⌘E**：导出标签组为 Markdown 文件（多选时按标签分组）

### 卡片上的标签
- **双击卡片上的标签胶囊**：移除该标签

## 分类与排序

### 收藏（⭐）
- 点击卡片右侧星形图标，切换收藏/取消
- 收藏条目**永久保留**，不受清理策略影响
- 收藏后自动清除置顶状态
- 至少 1 条收藏时，底部出现「☀️ 收藏」标签页

### 置顶（📌）
- 点击卡片右侧图钉图标，切换置顶/取消
- 置顶条目排序高于普通条目
- 置顶 7 天后自动取消（退回常规列表）
- 至少 1 条置顶时，底部出现「📌 置顶」标签页

### 排序规则
收藏 > 置顶 > 常规（按时间倒序）

---

## 数据管理

### 保留天数
- 展开设置行 → 选择 1/3/5 天
- 常规记录超期自动清理
- 收藏记录永久保留
- 置顶记录 7 天到期后转为常规，按常规规则清理

### 清理历史
- 点击底部 🗑️ 按钮，清除所有非收藏、非置顶的常规记录

### 删除单条
- 点击卡片右侧垃圾桶图标

---

## 窗口外观

### 窗口颜色
- 展开设置行 → 点击 ☀ 按钮切换深色/浅色模式

### 快捷键设置
- 展开设置行 → 点击对应胶囊进入录制模式 → 按键 → 自动保存
  - 「新建标签」：默认 ⌘G
  - 「快捷窗口」：默认 ⇧⌘V
  - 「导出标签组」：默认 ⌘E

### 开机自启
- 展开设置行 → 右侧开关按钮

---

## 自动更新

- 启动时自动检查 GitHub Release 更新
- 发现新版本弹窗通知，点击下载安装
- 无需 Apple Developer 账号，免费分发
- 首次安装需**右键 → 打开**绕过 Gatekeeper
