- [x] `Resources/appcast.xml` — 更新源模板，指向 GitHub Releases

### 第 3 步：UI 打磨
- [x] `Managers/MenuBarManager.swift` — 去掉导出弹窗的格式选择器（只有 Markdown）

### 发布流程（用户手册）
1. `./Scripts/build.sh` → 输出 `CopyCapsule-2.0.0.dmg`
2. `./Scripts/sign-update.sh CopyCapsule-2.0.0.dmg` → 生成签名，更新 `appcast.xml`
3. 上传 DMG 到 GitHub Releases，commit + push `appcast.xml`
4. 用户端 Sparkle 自动检测 → 弹窗提示下载
