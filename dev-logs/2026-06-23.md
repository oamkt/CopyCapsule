# 开发日志 - 2026-06-23

## 多选标签组导出（v2 后增强）

用户需求：之前只能单选一个标签后 ⌘E 导出，需要支持同时选中多个标签并一次性分组导出。

### 改动

- [x] `Services/ClipRepository.swift` — 新增 `fetchByTags(_:limit:)` 多标签 OR 查询，id 去重
- [x] `Services/ExportService.swift` — 签名改为 `export(itemsByTag:format:to:)`，Markdown 按标签分段，跨标签去重
- [x] `ViewModels/ClipHistoryViewModel.swift` — `selectedTag: String?` → `selectedTags: Set<String>`；`filterByTag` → `toggleTag`；新增 `filterBySelectedTags()`；`exportCurrentTag` → `exportSelectedTags`
- [x] `Views/HistoryPanelView.swift` — 标签栏点击改为 toggle 行为，高亮改用 `selectedTags.contains`
- [x] `Managers/MenuBarManager.swift` — `handleExport()` 适配多标签，对话框标题/文件名更新
- [x] `swift build -c release --disable-sandbox` 编译通过零错误

### 交互模型

- 点击标签 = 切换选中/取消（toggle）
- 多选时 OR 逻辑合并显示所有含任一标签的条目
- 导出 Markdown 按标签分组，共享条目只出现在第一个匹配标签下
- 纯文本/RTF 类型导出，图片/文件自动跳过
