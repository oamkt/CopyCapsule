# 开发日志 - 2026-07-08

## 新用户默认跟随系统颜色

### 问题
`useDarkMode` 默认 `false`，导致 `applyAppearance()` 强制设为浅色模式，新用户不管系统是深色还是浅色都显示浅色。

### 修复
**`Models/Settings.swift`**:
- 新增 `hasSetAppearance` 计算属性：通过 `UserDefaults.object(forKey:) != nil` 判断用户是否主动设置过外观
- `init()` 中 `useDarkMode` 改用 `ud.object(forKey:) as? Bool ?? false`（与 `bool(forKey:)` 效果相同，但配合 `hasSetAppearance` 可区分"未设置"与"设为false"）
- `applyAppearance()` 增加 guard：未设置过 → `NSApp.appearance = nil`（跟随系统）；已设置 → 按用户选择强制 dark/light

**`Views/HistoryPanelView.swift`**:
- 新增 `isEffectivelyDark` 计算属性：未设置时读取系统实际外观，已设置时用 `useDarkMode`
- 主题按钮首次点击：检测当前系统外观，翻转到对面（避免首次点击"无变化"）
- 按钮图标和 tooltip 改用 `isEffectivelyDark`

## Shifth+点击主题按钮 → 重置为跟随系统

### 实现
**`Models/Settings.swift`**:
- 新增 `resetAppearance()`：移除 UserDefaults 中的 `useDarkMode` key，设置 `NSApp.appearance = nil`（回到跟随系统）

**`Views/HistoryPanelView.swift`**:
- 主题按钮增加 Shift 检测：`NSApp.currentEvent?.modifierFlags.contains(.shift)`
- Shifth+点击 → 调用 `resetAppearance()`
- tooltip 增加 `| ⇧点击重置为跟随系统` 提示
