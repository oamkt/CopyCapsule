## 阶段 12 剪贴板增强 ✅ 完成

- [x] `ClipboardMonitor` 新增 `imageExtensions` 和 `maxFileReadBytes` 常量
- [x] `ClipboardMonitor.readImageFromFileURL()` — 从 pasteboard 文件 URL 读图片并转 PNG

- [x] `ClipboardMonitor.fileURLs()` — 两阶段提取 pasteboard 文件 URL（pasteboardItems + 回退）
- [x] `ClipboardMonitor.readPasteboardItem()` — 5 步优先级（图片数据→图片文件→RTF→文字→文件）
- [x] `ClipCardView.filePreview` — 补充来源应用名显示
- [x] 编译验证通过 ✅

### 图片修复逻辑
- 从 Finder 复制或截图：pasteboard 上通常只有 `.fileURL`，无 TIFF/PNG 数据
- 新增 `readImageFromFileURL` 检测图片扩展名 → 从磁盘读取 → 转 PNG → 存储
- 同一图片两次复制：相同 PNG 数据 = 相同哈希，去重生

### 文件支持逻辑
- 非图片的 `.fileURL` → 创建 `.file` 类型 ClipItem
- 只存文件路径，不存内容（方案A）
- 去重基于路径哈希：同一文件两次复制不重复
