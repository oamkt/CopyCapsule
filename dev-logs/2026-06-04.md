## 技术栈总结

| 层 | 技术 |
|----|------|
| UI | SwiftUI + AppKit |
| 入口 | 传统 main.swift（避开 Swift 6 @main 并发限制） |
| 数据 | SQLite3（系统内置） + FTS5 全文搜索 |
| 快捷键 | Carbon RegisterEventHotKey（零权限） |
| 开机启动 | SMAppService（macOS 13+） |
| 去重 | SHA-256（CryptoKit） |
| 构建 | SwiftPM + build.sh |
