# 开发日志 - 2026-06-18

## 标签组导出功能（v2 后新增）

用户需求：按标签组批量导出文字内容，快捷键触发（界面已饱和）。

### 需求决策
- [x] 三种格式：TXT / Markdown / PNG 卡片
- [x] 触发方式 A：筛选标签后按 ⌘E 导出
- [x] 快捷键默认 ⌘E（keyCode 14, command），可在设置中修改

### 第 1 步：快捷键配置
- [x] `Models/Settings.swift` — 新增 `exportShortcut` 属性，默认 ⌘E
- [x] `Views/ShortcutRecorder.swift` — 新增 `Shortcut.defaultExport`，displayString 已有 E 映射

### 第 2 步：ExportService
- [x] 新建 `Services/ExportService.swift`
  - `enum ExportFormat` — txt / markdown / png
  - `exportAsTXT` — 分隔线 + 时间戳 + 来源 + 内容
  - `exportAsMarkdown` — # 标签标题 + ### 日期·来源 + > 引用
  - `exportAsPNG` — 600pt 宽卡片，Accent 蓝顶条 (#5AACFA)，纵向拼接长图
  - 仅导出 text/rtf 类型，图片/文件自动跳过

### 第 3 步：ViewModel
